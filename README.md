问题：
1、linux为什么setup要加载在0x90200地址上？
Linux 0.12 启动时，setup 被加载到 0x90200，这是一个经过设计的内存布局选择，主要是为了避开 bootsect、保护 BIOS 数据区，并为后面的内核加载腾出空间。
2、为什么bootsect.S会移动自己？每次上电都会移动吗？
bootsect.S 每次启动都会从 BIOS 给它的固定地址 0x7C00，把自己复制到 0x90000，是为了腾出低地址空间，并给 setup 和 kernel 的加载安排稳定的内存布局。这是 Linux 0.12 在只有 512 字节启动扇区限制下采用的启动策略。
